# VLA 技术博客 GIF 分镜：同步 → 取窗 → 组样本

> **状态：三段原生 Manim 视觉原型已渲染，尚未完成插件契约集成／用户视觉验收。** 原型见 [vla_prototype.py](<../renderer/vla_prototype.py>)；schema、Host 和客户端仍不接受 VLA 模板。依据：[统一视觉规范](<visual-vocabulary.md>)、本次用户对参考图的概念说明；不是截图逐字 OCR，不是用户真实数据集或训练配置。

## 1. 视觉论点与范围

**一句话：同一 episode 的相机画面、状态与动作按时间对应，再从同一段记录取多个可重叠窗口，最后把各模态的固定长度片段与稳定任务上下文组成样本。**

目标：**3 个独立、各 8 秒、最后 2 秒完全静止**的博客 GIF。每片只有一个核心动作：同步游标推进、选择窗口平移、已选片段复制归位。不是 24 秒长片、完整截图复刻、盒子幻灯片、流水线吞吐展示或机器人控制演示。

- **用途／读者**：不熟悉 VLA 的技术博客读者，一眼看出“同一时刻／同一段记录／同一个样本”，先看动作再看符号。
- **气质**：科学插图＋克制的编辑式排版；浅灰底、深灰字、大留白、精确轨道，不是 SaaS 卡片仪表盘。
- **记忆点**：同一条竖向游标穿过模态轨道，之后复用为取窗边界和来源对应。对象身份延续，不靠换页说明。
- **叙事**：短标题提出问题 → 局部动作演示 → 动作显现关系 → 末帧结论；不加独立标题页。
- **低阅读负担**：标题不超过 12 个中文字符；阶段注释单条不超过 10 个中文字符（数学符号另计）。不塞 recipe、张量维度或多行段落。

## 2. 供后续机器分镜引用的来源文本

以下是**根据用户对参考图的概念解释整理的规范化来源文本**。后续项目可将其作为 source 并引用精确子串；它不是截图原句。引用检查不能证明截图逐字核验、数据真实性或科学语义。没有真实相机文件、数值序列或训练配置输入。

> 合成示意：本图解释 VLA 数据的时间对应、窗口截取与样本组装，不代表用户提供的真实数据集或训练 recipe。
>
> 在同一 episode 中，时间帧按时间对应 K 路相机视觉、状态与动作；任务上下文在本示意的 episode 内保持稳定。
>
> 一个样本包含来自同一 episode 的模态片段与任务上下文。视觉片段长度用 Nv 表示，动作片段长度用 Na 表示；各模态的长度按其样本规则固定，但不据此断言不同模态长度相等。
>
> 同一 episode 可以取得多个窗口；窗口可以重叠，但不能跨越 episode 边界。
>
> 参考图展示的 30 FPS、Nv、Na 是概念示意，不是已经确认的用户实际采样率、窗口长度或训练 recipe。本分镜不推断具体相机数、张量维度、采样步长、插值规则、因果方向或未来动作范围。
>
> 本分镜使用 t₀、t₁、t₂ 等示意时间标签。机器人线稿和任何姿态、状态或动作展示均为合成示意，不是真实采集记录；GIF 的播放帧率与数据采样 FPS 是不同概念。

### 来源边界

| 内容 | 允许 | 禁止推断 |
|---|---|---|
| K | 相机路数符号，一个相机组标“K 路” | 从可见图标数猜实际 K |
| Nv／Na | 视觉／动作符号长度，同一规则下各自固定 | 实际值、Nv=Na、比值、tensor shape |
| state | 状态片段、时间对应、该模态规定长度 | 未提供的维度、数值或采样公式 |
| task | 本示意 episode 内稳定 | 所有数据集永远不变、任务导致动作的因果证明 |
| 时间 | t₀、t₁、t₂、… 顺序标签，共同坐标映射 | 等间距绘图证明真实等采样、延迟或时间戳 |
| 窗口 | 同 episode，可重叠，边界约束 | 确定 stride、必重叠、跨 episode 拼接或 padding |
| action | 时间对应的记录／已选片段 | state→action、预测 horizon、按动作计算机器人运动 |
| 30 FPS | 必要时注明“参考图示意，非实际 recipe” | 当真实采集率，或与 GIF 播放 FPS 混淆 |

画面默认**不展示 30 FPS 或任何数值状态／动作**。未来若必须展示，需明确来源与示意条件，不由 renderer 补值。机器人采用两段机械臂＋夹爪＋固定物体线稿，姿态只用于区分合成相机帧，没有数值到运动的物理映射。

## 3. 统一视觉与稳定锚点

以下为设计目标，不是新增运行配置。

- 1280×720、16:9，在 640×360 博客尺寸仍可读。正文中文目标 32–36 px，标题 46–52 px，“合成示意”最低 24 px；不得以缩字解决溢出。
- 左上原点百分比：标题 `(6%,8%)`，task `(6%,20%)`，时间区 `x=24%..90%, y=35%..73%`，阶段注释 `(24%,83%)`，来源脚注 `(6%,94%)`。文字变化不能使锚点漂移。
- 同一左侧标签、左→右时间方向、episode 边界样式。episode 在博客配文解释为“一段独立连续记录”，画面简称“一段”。C 固定来源区 `x=24%..49%`，样本区 `x=65%..90%`；三模态槽位 `y=38%,53%,68%`，任务槽位 `y=24%`，task 原件仍在原锚点。各副本仅平移到对应槽位，不改变尺寸；所有区域预先留空，不中途缩放整图。
- 背景 `#F3F4F5`，正文 `#20252B`，轨道 `#C7CDD3`；视觉蓝 `#2878CF`、状态青 `#087F85`、动作橙 `#C76316`；task 灰黑。实现需检查实际对比度。
- **三种语义色不等于三个独立亮点**：非当前对象低饱和，当前联动组使用饱和细边。同步模态视作一个注意力中心；游标／窗口用深灰粗线和局部灰底，不新增第四种亮色。
- 颜色之外有“视觉／状态／动作”标签和相机／向量／动作图标；窗口有边界与括号，episode 有截断竖线与名称。灰度静帧仍可理解。
- 每阶段最多一条短注释，在预留空白区淡入淡出；前条退出再进后条，不遮相机、刻度、边界或符号。标题／图例／来源条件常驻。
- 可选手绘仅机器人或非数据装饰线：一次生成、确定性、跨帧复用；轨道坐标、刻度、窗口、数据、文字完全精确。无逐帧随机噪声／抖动／弹跳／数据变形。默认精确线稿已足够。

## 4. GIF A：同步帧（0–8 秒）

**固定标题**：“同一时刻，看什么？”
**一个动作**：共同游标从 t₀ 推进到 t₂，视觉／状态／动作同相更新。
**末帧结论**：“同帧对应，任务不变”。

### 场景对象

一条时间轴＋三条模态轨道。视觉用相机束图标＋“K 路”，不铺未知 K 行；一个视觉面板代表相机组。每轨只有一个固定的当前面板：视觉为合成机器人线稿，状态为 `s(t)` 向量图标，动作为 `a(t)` 记录图标。task 为静止灰块“任务上下文”，不写未经来源支持的具体指令。三个面板共用时间标记，不以 state／action 驱动机器人运动。机器人是视觉面板里的具象锚点，不是额外动作中心。

| 秒区间 | 动作／技术意义 | 注释时刻 |
|---|---|---|
| 0.0–1.0 | 静止骨架直接可见，游标在 t₀；task、标签、来源常驻；不逐卡飞入 | “同一时刻”0.2–0.5 淡入 |
| 1.0–3.0 | 游标匀速 t₀→t₁；三个模态同相，到 t₁ 同时更新；当前面板位置不变 | 前条 2.7–3.0 淡出 |
| 3.0–5.0 | 游标 t₁→t₂；再次共同更新，保留 `s(t₂)`／`a(t₂)` 共同下标；task 不变、不高亮 | “一起更新”3.2–3.5 淡入，4.7–5.0 淡出 |
| 5.0–6.0 | 停在 t₂，三处边线形成同帧强调；最后局部淡化于 6.0 前完成 | 结论 5.2–5.5 淡入，保留 |
| 6.0–8.0 | **2.0 秒完整静帧**：t₂、当前三模态、task、结论、“合成示意” | 无移动、呼吸、淡化或 reset |

**原生 Manim**：`Line` 轴／刻度、`VGroup` 轨道、`Rectangle` 面板、`Text` 中文／符号、`VMobject` 线稿／图标；一个 `ValueTracker` 驱动游标。预定义面板组使用 `Transform`／交叉淡化，三模态同相，不能各路独立计时。准确转场区间：t₁ 内容共同交叉淡化 2.7–3.0，t₂ 内容共同交叉淡化 4.7–5.0；不对未提供的中间数据插值。

**一眼验收**：读者能指出同一个 t₂ 的三个记录，以及未变化的 task；不是三行串行处理。

## 5. GIF B：移动窗口（0–8 秒）

**固定标题**：“一段记录，取多窗”
**一个动作**：同一选择器平移，留下旧窗口灰轮廓，显示重叠并停在 episode 内。
**末帧结论**：“可重叠，不跨段”。

### 场景对象

复用三轨、task、时间轴，背景记录不再更新。episode A 右端有竖线＋“段结束”；边界外只留浅灰短线＋“另一段”。选择器是公共时间参考框，各模态有独立截取括号：视觉 `Nv`，动作 `Na`，state “状态片段”。**公共框不断言不同模态实际长度、频率、起止相同**；括号几何宽度仅为合成示意，不可反推比例。只展示 W₁／W₂；W₁ 静态灰轮廓，W₂ 唯一活动焦点。位移不是确认 stride；边界停住不推断补齐／丢弃规则。

| 秒区间 | 动作／技术意义 | 注释时刻 |
|---|---|---|
| 0.0–1.0 | 三轨、episode A 边界、task、W₁、Nv／Na 直接可见 | “同一段记录”0.2–0.5 淡入 |
| 1.0–2.0 | W₁ 的各截取括号共同加强边线，记录不动 | 前条 1.7–2.0 淡出 |
| 2.0–4.5 | W₁ 原位留灰轮廓；活动选择器平移成 W₂；各括号保持自身长度，同一时间映射平移；真实几何交集可见 | “窗口可重叠”2.2–2.5 淡入，4.2–4.5 淡出 |
| 4.5–5.5 | W₂ 完成末段平移至合法位置，最右截取端不越过 episode A；灰色阻断符表明不跨段，不先越界再弹回 | “不跨段”4.7–5.0 淡入 |
| 5.5–6.0 | 选择器停止，重叠保留静态细纹／括号 | 前条 5.5–5.7 淡出；结论 5.7–6.0 淡入 |
| 6.0–8.0 | **2.0 秒完整静帧**：旧窗、新窗、交集、episode 边界、结论 | 末帧直接跳回 W₁，无 reset |

**原生 Manim**：`Line` 轨道／边界、`Rectangle` 选择器、`Brace`／短线截取括号、`VGroup` 各模态范围、`Text` W₁／W₂／Nv／Na。同一 `VGroup.animate.shift` 或保持尺寸的 `Transform`；历史轮廓为静态副本。重叠必须画实际交集，不靠字幕代替；括号不伸缩。

**一眼验收**：两窗口交叠，活动窗口仍在同一 episode 内；无 Nv=Na 或比例公式。

## 6. GIF C：样本组装（0–8 秒）

**固定标题**：“片段怎样成样本？”
**一个动作**：已选的三模态片段与 task 复制到右侧固定槽位；内容不变，仅逻辑重组。
**末帧结论**：“同段片段，组成样本”。

### 场景对象

左侧 episode A 的已选来源，保留 B 的窗口／标签，不重演取窗。块标“视觉 Nv”“状态片段”“动作 Na”，task “任务上下文”；各自定长，不用相同小格数暗示等长。右侧四行槽位视觉／状态／动作／任务，外侧一个括号＋“sample”，不是四层嵌套卡片。复制保留来源身份；源到槽位连线无箭头，只表示来源，不是因果。task 原件静止、副本归位。不展开 tokenization、拼接轴、batch、模型输入顺序或 tensor shape；组样本不等于确定物理内存拼接。

| 秒区间 | 动作／技术意义 | 注释时刻 |
|---|---|---|
| 0.0–1.0 | 左侧已选片段＋task、右侧空槽位直接可见；episode A／“合成示意”常驻 | “来自同一段”0.2–0.5 淡入 |
| 1.0–2.0 | 四对象作为同一来源组加强边线，各自符号长度不变 | 前条 1.7–2.0 淡出 |
| 2.0–4.5 | 四个副本作为一个联动组平移到对应槽位，原件不消失；不改内容／尺寸／长度 | “保留各自长度”2.2–2.5 淡入，4.2–4.5 淡出 |
| 4.5–5.5 | 副本归位，来源短连线淡入，样本括号完成；不再次弹跳或改 shape | “组成一个样本”4.7–5.0 淡入，5.2–5.5 淡出 |
| 5.5–6.0 | 样本最终饱和细边、来源灰静态；完成结论 | 结论 5.7–6.0 淡入 |
| 6.0–8.0 | **2.0 秒完整静帧**：左来源、右样本对应、task、Nv／Na、结论 | 不组第二个样本，无 reset |

**原生 Manim**：`VGroup` 块＋`Text`、`Rectangle`／简单折线槽位、`Brace` 样本括号、`Line` 无箭头来源线。副本保持尺寸平移，或严格保持尺寸的 `TransformFromCopy`；不能缩整张 matplotlib 截图到 sample 卡片，不能旋转／拉伸／粒子打散／弹簧归位。

**一眼验收**：每个槽位可反指来源，task 有原件与样本引用；Nv／Na 不换成数值或相等声明。

## 7. 通用组件词汇与机器契约提案

本节供 Host／schema／renderer worker 共同评审，是**语义合同草案，不是现有 API 字段或已实现 JSON Schema**。不得单方面照写实现。现有 schema.js 仍是分镜机器契约；technical 新能力需另行完成共享校验、编辑、渲染和存储验证。

| 组件 | 职责 | 参数语义／约束 |
|---|---|---|
| timeline | 固定有序参考轴 | id、anchor、范围、刻度位置与标签、方向、segment 边界；区分数值轴／示意标签 |
| track | 一类内容共用参考坐标 | id、timeline 引用、固定 anchor、标签、语义角色、显示范围；不从位置猜频率／因果 |
| window | 同 segment 的截取范围 | id、segment 引用、各 track 范围、参考位置、标签、合法移动端点；不隐式补齐／跨界 |
| block | 有身份的记录／片段／分组 | id、source 引用或 schematic 标记、角色、标签、长度符号、固定尺寸、anchor；副本继承来源 |
| annotation | 短阶段文字 | id、文字、固定空白区、进入／退出时刻、最终结论标记；不替代常驻图例／来源 |
| icon | 具象／符号锚点 | id、支持的图形类型、固定几何参数、schematic 标记；不接受任意执行脚本 |

### 有界参数与动作

- 每片 **≤18 可见时间刻度、≤5 轨道、≤12 逻辑 block，包含移动副本**。本例主时间标签 A=3、B=3、C≤4；三模态轨道=3；block A=4、B≤4、C=8（四原件＋四副本）。装饰轮廓／空槽位不计 block，若增加实际数据格必须重新计数，不用嵌套逃限。
- 相机组一轨一块，不实例化未知 K 行；K／Nv／Na 是符号文字，不能直接当数组长度或循环次数。
- duration=8、final hold=2；覆盖 `[0,8]`，全部动作／淡化于 6.0 结束。小数是内部动作时刻提案，不改变现有 durationSeconds 整数约束。
- 有界动作词汇：显示／淡化、同步时间推进、平移窗口、保持尺寸复制归位、强调来源组、静态保持。目标引用存在、复制来源确定、起止时刻与 easing 显式；不接受用户 Python／JS／eval／updater 函数。
- 时间匀速；窗口／归位单调无过冲缓动。禁止 bounce、elastic、随机 motion、晃动 reset 或全图无关闪动。
- timeline／track／窗口共用确定坐标映射；截取端全程在一个已声明 segment 内；每模态截取长度平移前后不变，不自动推断 Nv／Na 比例或相等。
- 保留完整概念 source、精确 evidence、来源类别“用户参考图概念说明的整理”、合成标记。真实数值／单位／采样率／维度须独立来源和显式输入，不能复用概念说明冒充数据证据。
- 碰撞、中文字体不可读、溢出或超量必须明确拒绝／要求拆分，不截字／缩到小字／省未知模态／静默 fallback 到 flow。
- 主代理协调实际字段映射和共享合同；没有实现的动作不声称可执行。

### 复用

复用 timeline 坐标、三类 track、task、相机／向量／动作 icon、注释区、来源标记。A 当前帧组 → B 背景记录与窗口 → C 已选片段，是读者可认出的对象延续。每片独立加载必要锚点，不依赖前片运行状态；不开镜头 pan／zoom，不造第二套风格。

## 8. Matplotlib／Celluloid 与 Manim 分工

- **Matplotlib**：有来源的科学图表、曲线／柱状图、精确轴与单位，固定尺度，数据不得为节奏变形。
- **Celluloid**：记录 Matplotlib 有界阶段快照，适合图表渐进显现；不是通用插图对象树。整张快照不能提供窗口独立平移或片段保留身份归位的对象语义。
- **Manim 原生对象**：本例游标、时间轨道、窗口、片段副本、机器人线稿与对应连线；Transform 是机制，不是换页装饰。
- `ImageMobject` 导入整图只得到整图移动／淡化，不自动有逐曲线／节点形变。精细联动需原生 Mobject 或明确受控 SVG 转换，保留坐标／身份。
- 三片默认不需要 Celluloid 科学曲线或外部图像服务；未来科学图单独一层，不为“用了 Celluloid”塞无来源曲线。
- 本设计不安装、不启动服务器、不写执行代码、不渲染。后续 render worker 先最低质量 smoke，再中文／布局／节奏，最终 GIF／末帧验收。安装、import 或 MP4 成功不等于 GIF 解码与视觉通过。
